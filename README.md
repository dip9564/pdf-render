# PDF Render

All-in-One PDF Editor & Generator — 100% client-side, no server uploads.

## Features

- **Image to PDF** — Convert images to PDF with custom layouts, filters, and page sizes
- **Image Editor** — Crop, rotate, flip, and apply filters to images
- **Merge PDF** — Combine multiple PDFs into one document
- **Split PDF** — Extract pages, split by ranges, or separate every page
- **Page Organizer** — Visually reorder, delete, rotate, and duplicate pages
- **Compress PDF** — Reduce file size with adjustable compression levels
- **PDF to Images** — Convert PDF pages to PNG or JPG
- **Add Watermark** — Text or image watermarks with custom styling
- **Annotate PDF** — Add text, shapes, drawings, and signatures
- **Rotate PDF** — Rotate all or selected pages
- **Edit Metadata** — Edit document title, author, subject, keywords

## Tech Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- pdf-lib (PDF creation/manipulation)
- PDF.js (PDF rendering)
- JSZip (ZIP downloads)
- Zustand (state management)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

```bash
npx vercel
```

## Privacy

All file processing happens entirely in your browser. No files are uploaded to any server.
